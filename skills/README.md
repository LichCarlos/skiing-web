# Skills 目录

`skills/` 用于存放项目级技能说明，当前只有本文件。此目录不参与前端构建，也不会自动注册到任何开发工具。

2026-11-06：从 GitHub 官方仓库固定版本安装 `frontend-design` 和 `web-design-guidelines` 至用户技能目录；本仓不复制第三方 skill 源码。用途、来源、安装命令和许可证说明见[网页设计方法与 Skills 研究](../docs/engineering/ui-design-research-20261106.md)。

新增技能时使用 `skills/<名称>/SKILL.md`，说明适用场景、操作步骤、验证方式及依赖。需要工具发现该技能时，再按所用工具的配置方式接入。
