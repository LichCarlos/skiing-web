新建字段
字段键
数据保存时使用的唯一标识，如 facilities；小写字母开头，可含数字和下划线，创建后不可修改。
显示名称
业务表单展示的字段名称，如“配套设施”，最多100字。
数据类型
单选
决定填写控件和校验方式；单选、多选需绑定选项字典，创建后不可修改。
分组
选择已启用的字段分组
选择当前业务实体下已启用的分组，决定字段在表单中的归属。
排序
填写非负整数；数值较小的优先展示。
选项字典
知识文章分类（knowledge.article_category）
从已启用的字典中选择，显示名称与系统标识便于核对。没有合适的选项时，先在数据字典中新建选项字典。
默认值（JSON）
文本用双引号，如 "双板"；数字用100，多选用["parking"]。留空清除默认值。
校验规则（JSON）
填写 JSON 对象：文本可用 minLength、maxLength、pattern；数字可用 min、max。留空清除规则。
必填
启用后，保存业务内容时必须提供该字段的有效值。
可搜索
允许查询功能使用该字段搜索；不会自动给所有页面增加搜索框。
可筛选
允许查询功能按该字段过滤，需相应业务页面接入。
可排序
允许查询功能按该字段排序，需相应业务页面接入。
公开字段
允许公开读取；仅系统管理员可开启，业务内容仍需满足自身的公开条件。
