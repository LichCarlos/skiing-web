# 项目知识与事件重试真实 HTTP 联调

负责人：Web Admin。状态：六项新增场景、管理全套 27 项及后端持久化核对通过。契约保持 OpenAPI 1.51.1 / 143 操作，无新增接口或业务规则。入口见[管理端独立 HTTP 联调](admin-authorization-live-http.md)，证据见[本仓摘要](../validation/content-events-http-20261103.json)。

前端使用生产 `apiRequest`、项目知识表单构造/读取/状态命令、`KnowledgeWriteGate`，以及事件列表/精确定位/重试和 `EventWriteGate`。测试连接编译后的 Nest 与全新 PostgreSQL 17 / pgvector 临时库，不导入后端或数据库代码。

| 新增场景   | 已验证结果                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 知识授权   | 自定义角色即使持有全部六项知识 grants，七种读取/写入请求仍被仅 system_admin 的规则拒绝                                                                                       |
| 草稿创建   | 生产表单和同步写门禁成功创建；列表关键词/状态筛选、完整详情投影正确；自行写 status、执行脚本正文、含账号密码的来源 URL 均拒绝                                                |
| 更新与发布 | 草稿编辑、首次发布和发布后编辑成功；更新带原始 version，旧版本 API 返回 409，生产预读发现旧版本后不发送写入；已发布编辑保留 published 和首次发布时间                         |
| 撤回与删除 | 撤回、重新发布和软删除成功；首次发布时间保持，删除后列表排除、详情 404，后端另验证实际软删除，未将 404 本身当作删除证明                                                      |
| 事件定位   | 组合筛选、偏移分页及十二项元数据投影正确；生产定位器通过一毫秒时间窗口找到数据库中 `.123456` 的原事件，精确匹配 EventId；内部 Payload、LastError 和 LockToken 不返回         |
| 人工重试   | 非管理员即使持有事件 list/retry grants 也不能读取或重试；生产门禁只提交一次，failed→pending，累计 Attempts=5 保持，上限 5→13；旧快照预检阻止重放，pending 的直接重试返回 409 |

后端直接核对知识版本最终为 7、保留已发布修订正文和首次发布时间、DeletedAt 非空；七条 `project_doc.changed.v1` 和七条知识审计逐条对应。事件重试没有新建 EventId，只有一条成功重试审计；原始微秒 CreatedAt/OccurredAt、Payload、LastError 保持，无租约、无发布完成标记。拒绝请求没有成功审计。既有 21 项授权、商家、字典、字段、日志、AI 审计与 RAG 场景继续通过。

首轮夹具错误地给 failed 事件设置租约，被 `OutboxEvent_lease_check` 拒绝；该失败环境已停止并保留日志。修正测试数据为合法无租约失败状态，在新临时库完整通过。没有关闭或放宽数据库约束，也不声称本轮验证了从非法带租约 failed 状态恢复。

这证明生产前端模型经真实 HTTP 与数据库协作，不代替实际 React 点击、浏览器 Cookie/CORS、BFCache 或设备验收。状态命令仍无客户端 expectedVersion；编辑的 version 保护不能扩大为全部命令或跨设备幂等。Kafka 投递与消费者关闭，pending 只表示落库/受理；模型索引、真实 Embedding/对话供应商、容器及远程 CI 另待验收。没有启动 Next、Expo Web 或 Docker。
