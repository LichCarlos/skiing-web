# AI 会话审计读取与正文生命周期

负责人：Web。依据：已确认 D-47 / ADM-19 / API-AI-04。当前三仓 OpenAPI 1.51.1 / 143 操作，D-52 引用声明已确认并修正；未新增路由、权限或数据库迁移。此前 [1.51.0 阶段验证摘要](../validation/ai-audit-lifecycle-20261103.json)保留当时的检查与真实 HTTP 结果；本次类型同步和 RAG 修复以[后续摘要](../validation/rag-source-lifecycle-20261103.json)为准。

元数据读取先后复核 /auth/me，解析当前身份并比较账号 ID、账号、去重排序后的角色和权限。管理入口与审计列表权限共同生效；不按商家或管理员角色键推断审计能力。列表校验分页/total/条数/重复会话，详情核对精确 UUID；元数据只保留 conversationId、userId、status、createdAt、updatedAt、deletedAt、messageCount 七项。页面固定列出这七项，不遍历任意响应属性，额外标题、账号、正文或模型信息不能进入显示状态。

正文读取单独要求 read-content grant、有效 UUID 和 trim 后 1–500 字原因。POST 前后均复核身份；只调用一次正文访问命令，不因网络异常、响应格式错误或最后身份读取失败而自动重放。所有请求传递同一个 AbortSignal 和 no-store。正文模型仅保留 messageId、sender、content、generationStatus、createdAt、citations；BigInt 保留字符串，拒绝重复 ID、错误字段和非 JSON 引用。存储 citations 按历史 JSON 展示，不将当前引用 VO 强加给旧消息。

正文协议未回显会话 ID。客户端固定请求路径并校验对应详情，但不能仅凭正文响应独立证明会话归属；服务端对目标和 owner 数据范围的授权仍是最终依据。读取后身份复核也不能取代服务端事务内权限检查。

AuditContentSession 是本页面的内存实例，管理同步单请求锁、激活令牌、可见性和读取代次。隐藏、pagehide、清除、重新加载元数据或卸载都取消请求并清空正文；忽略不遵守取消信号的迟到结果。取消不立即释放尚未结束的本地请求锁；旧结果/旧清理不能恢复正文或清除新实例的状态。pageshow/恢复可见不会自动读取，必须再次明确操作。该实例不写本地存储，不跨组件或设备保存原因、正文、响应或凭证。

错误展示只允许已知输入、身份和响应校验消息及固定 HTTP 提示，未知异常不直接回显。未知结果可能已经写入访问审计；再次手动读取是一次新的受审计访问，前端不声称提供服务端幂等或回滚。
