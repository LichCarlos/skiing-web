# 官网栏目颜色、滚动留停与品牌页脚

本轮交付官网全部路由的配色与公共组件优化。保留真实业务数据、会话、文章与社区接口；后台与Expo属于独立界面，本次不构建或发布APK。

## 颜色如何参与交互

采用成熟设计系统共同使用的规则：颜色承担稳定角色、导航与目的地一致、阅读区保持克制，同时提供文字和形状线索。可参考 [Material 3 色彩角色](https://m3.material.io/styles/color/roles)和[WCAG 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。这些是设计依据，不代表获得外部设计师评审。

| 路由/组件                      | 背景           | 前景与用途                     |
| ------------------------------ | -------------- | ------------------------------ |
| `/snow`                        | 黄色 `#FFDA3D` | 蓝色网格开场；黄色仅作首页画布 |
| 雪场导航与`/snow/resorts`      | 蓝色 `#2455F5` | 白字、白色表单与卡片           |
| 知识导航与`/snow/knowledge`    | 绿色 `#00AD47` | 黑字、白色文章卡片             |
| 社区导航与`/snow/dynamics`     | 红色 `#DC2F43` | 白字、白色动态卡片             |
| 文章、雪场、社区详情及平台信息 | 白色           | 黑色正文；蓝色主要操作         |
| 登录入口/提交                  | 蓝色           | 白字，与登录背景一致           |
| 公共品牌页脚                   | 绿色黑线网格   | 彩色格块、黑色品牌名与小雪花   |

官网全局主题恢复白色，首页用自身CSS变量覆写导航为黄色。栏目页用显式`data-page-tone`设置背景；查询参数不改变栏目颜色；详情不继承目录背景。文字、当前导航下划线和箭头辅助颜色定位。错误和不可用状态保持文字及恢复动作。

## 首页滚动

`HomeOpening`保留原生滚动渐出、纯网格、蓝色展示揭幕，新增100px入场与100px离场缓冲。蓝色展示增加2px黑边，平台名称白色、标语黄色，移除黄底文字条。

雪场`ScrollRail`在横向移动前后各保留100px；键盘焦点与前后按钮共用同一坐标映射，增加总高度200px。知识/社区使用`SectionHold`：适合视口的完整面板增加200px连续sticky停留；长面板保留上下100px缓冲并正常流阅读。手机/触摸、低高度与减少动画时使用正常流/原生横滑，不强行锁定长内容。无JS可读，所有观察器、RAF和监听器卸载时清理。

此处“锁定”为原生sticky停留，不承诺任意大滚轮增量都无法越过；不劫持wheel/touch、不阻断页面滚动。默认浏览器惯性不被重写。

## 页脚及登录

`BrandGridFooter`为本端公共视觉组件：正常页面完整品牌区，登录页76px紧凑版。网格为本地几何SVG重复背景，不加载第三方图像或脚本；黑线与格块明确保留。隐私/协议/平台信息和配置加载失败重试仍可访问。

登录取消中央SVG切换器，底部文字按钮切换；保留桌面左右平移40:60、固定卡片尺寸、确认密码、成功返回登录及密码清理。手机隐藏照片，删除原来为中央按钮预留的空间。紧凑品牌页脚与100dvh布局共同计算，极短屏仍允许表单内部滚动以确保可操作。

## 验证、发布与边界

冻结源码在专用WSL完成依赖锁校验、28个文件446项官网测试、ESLint、TypeScript、Next生产构建和standalone校验。先启动服务器环回候选并校验归档哈希、2167文件及21链接，再仅切换官网服务；保存unit和上一发布版本。

正式HTTPS浏览器验证涵盖首页、蓝绿红目录、文章白底详情、关于页、桌面登录/注册切换、390×844手机注册/社区。无合成账号或生产业务内容写入。候选通过SSH隧道访问时，正式API的CORS拒绝本地来源会导致会话无法确认；不修改安全策略，正式域名复验正常匿名会话。Windows跨盘依赖junction预览因Next开发入口解析失败，停止本轮专用预览，改用已构建候选与真实HTTPS验收；未停止既有3108开发服务。

具体构建ID、时间、SHA、截图、HTTP检查、回滚和未覆盖项见[验收报告](../validation/route-colors-grid-footer-20261106.json)。浏览器尺寸模拟不等于物理手机、屏幕阅读器、OS减少动画和200%系统缩放实测。源码中的无JS与减少动画降级需与实际验证区分。
