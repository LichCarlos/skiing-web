2026-11-09。延续 React Flow 12.12.1（MIT）及 Ant Design Tree，实现两处管理的拖拽创建与表单操作。只调整管理端，沿用现有数据库和 API。

## 使用方式

- 数据字典：展开“实体关系图”，将“新字典”拖到业务实体或空白处，填写字典表单；拖到业务实体会预选适用业务。该归类不会自动生成字段绑定。
- 将“新字典项”拖到已启用字典节点，读取该字典后打开新增表单；在下方字典树中拖到父级，会预填父级。拖到树的空白处创建根项目。
- 字典树的现有节点可拖到其他父级，弹出编辑表单核对后保存。禁止自己或后代作为父级；同级排序仍使用表单“排序”。搜索期间禁止移动现有节点，避免根据不完整层级误操作。
- 字段管理：选择业务，展开“拖拽管理字段”。将“新分组”拖到实体或空白处；将“新字段”拖到启用分组上会预选该分组，拖到实体或空白处则使用现有默认分组规则。
- 字段图支持点击已有字段/分组进入编辑、搜索定位、缩放和平移。初始显示可读范围；使用搜索查找其他字段。
- 手机使用层级树及同名创建按钮。每个拖拽源都提供点按创建，保持键盘可操作。

## 数据与写入边界

所有节点来自完整分页读取，重复 ID、分页总数漂移或任意读取失败均不显示部分字段图。按 `(EntityType,GroupKey)` 关联分组，按 `OptionsDictType` 关联字典，固定字段映射保持原有规则。扩展字段不是新增数据库表或物理列。

拖入只打开既有表单并传递上下文，不直接写库；保存成功后重新读取节点，取消不创建临时节点。创建权限、当前身份核对、版本条件、保存锁及未知结果恢复继续由原有模块处理。停用分组/字典、不兼容目标和嵌套分组不接受创建。树使用捕获阶段识别自定义 MIME，避免原生树拖拽消费外部创建事件。
