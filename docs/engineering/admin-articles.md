## 页面行为

列表将输入关键词与已提交筛选分开；搜索、状态筛选重置页码，分页与重试保留有效条件。读取以 RequestLane 取消前次请求，迟到成功、失败及 finally 不覆盖新筛选；加载时清除旧列表，错误、空结果、刷新和后续空页返回均有入口。表格横向溢出放在本端 CSS Module 中处理。

所有文章工作区先等待会话恢复，再检查管理入口与 content:article:manage。自定义角色具备相应授权即可使用，不按商家或角色名称推断。工作区 key 包含账号、有效角色键、权限键及目标，身份/授权/目标改变重建页面实例。列表、详情、字段目录和表单读取前调用 /auth/me 复核；请求使用 no-store，取消后不继续读取或渲染。编辑动态路由与路由授权共同限制规范正 int4 ID，拒绝 01、指数、小数、符号、空白和溢出。

编辑保留分类、AssetId 封面、正文和 D-40 字段控件；分类及必要选项字典失败时不展示不完整表单。提交 DTO 只包含已声明的标题、摘要、正文、分类、封面和可写变化字段，忽略 status、作者及隐藏/未知字段，保留未编辑值的省略语义，字段 null 仍交给后端必填/类型校验。封面保持十进制 bigint 字符串，不转 Number。

保存与发布/撤回改为独立操作。发布/撤回只作用于已保存内容；未保存修改或正在上传时禁止命令。保存成功回填服务端 VO，新建确认后进入对应编辑地址；写失败保留输入，不自动重发。刷新资料明确提示会替换当前输入。

## 写前复核与结果核对

ArticleWriteGate 在异步校验之前同步加锁，覆盖保存、发布、撤回和删除。准备阶段重读目标，检查当前状态与展示版本；保存另核对最新字段目录/策略与表单目录一致。正式写入前再次调用 /auth/me 比较账号、角色键和 grants，身份改变即拒绝。UI 隐藏/锁定只改善交互，后端仍独立执行 RBAC、数据范围和字段规则。

客户端浏览器内存台账按账号保存待确认动作；不存凭证、正文、扩展字段或封面 URL，只记录目标 ID 或新建标题。写请求发出后标为进行中；成功或明确 4xx（408除外）移除；网络、408、5xx或响应形态异常保留为未知结果。离开页面取消请求并隔离回调，台账仍保留。旧客户端请求尚未结束时禁止解除阻塞；结束后须重新读取目标及刷新列表/表单，再由操作员人工确认。

核对使用台账版本，读取过程中新增/结束的动作会使旧核对失效。新建只检索标题候选并明确要求人工核对，搜索不证明写入成功；目标404可能来自删除或失去范围，不能认定删除成功。明确成功后若导航失败，不将已确认写入重新标记未知。

## 验收边界

CurrentUserVO 尚不投影精确资源范围；前端不能推断 selected 账号可否新建，仍以后端拒绝为准。版本读取仅发现此前已发生的变更，既有 PATCH 未接收 expectedVersion；读取后至提交之间仍可能并发更新，本轮不宣称服务端乐观并发锁或即时撤权。

台账在浏览器内存，整页刷新、关闭标签页和其他设备不共享。客户端 fetch 结束/取消也不证明服务端事务已结束；人工核对不会提供 exactly-once。没有给既有内容写接口补造幂等键、版本字段或数据范围接口。后续若扩展这些协议须先定版，再实现。

专项为 8 文件/128 项，覆盖模型、查询编排调用、同步锁/竞争、取消、台账与 SSR/路由门禁；其中新增113项，原字段15项保留。测试使用请求替身，不代替浏览器点击、真实 Cookie/CSRF、对象存储和完整 API 工作流。三仓完整回归日志前缀 article-pages-。
