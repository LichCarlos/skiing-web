# 数据字典与字段管理使用说明

本说明按当前实现编写。入口均在管理端“系统设置”分组；界面是否可见、是否可以新建或编辑，取决于账号获得的具体权限。

可视化入口：数据字典 → **实体关系图**。选择业务后点击实体、分组、字段或字典节点进入对应配置；搜索可定位节点。字典详情默认层级树，节点旁可新增子项或编辑，父级使用树形下拉选择。详见[关系映射与操作](admin-dictionary-graph-20261109.md)。

2026-11-09 更新：日常添加分类使用“新增分类”下拉选择所属字段，系统匹配字典键及分组；需要新扩展选项时使用“新建选项字典”，选择业务后自动生成类型键。字段管理的选项字典也通过下拉绑定，不再手填引用标识。详见[分类字段下拉选择](admin-category-select-20261109.md)。下文键名示例用于解释保存与引用规则。

## 两个功能的分工

| 功能     | 配置内容                     | 示例（用于说明）                                 |
| -------- | ---------------------------- | ------------------------------------------------ |
| 数据字典 | 统一、可复用的选项及选项层级 | 雪场设施：停车场、餐厅、租赁中心                 |
| 字段管理 | 业务对象的扩展信息及填写规则 | 给滑雪场增加“配套设施”多选字段，选项取自设施字典 |

字典不是文章库；字段配置也不是某个雪场的实际资料。配置生效后，具体值在相应业务编辑表单里填写和保存。

## 数据字典

字典分为“类型”和“字典项”。类型键供系统引用，名称供人阅读，分组键用于归类。每项有显示名称、保存值、父级、颜色、排序、默认项和启用状态；父级可组织树状选项。

例如类型键 `resort_facility`、名称“雪场设施”，选项“停车场”保存为 `parking`。“名称”和“值”分别承担显示和存储用途；已有数据引用某个值时，调整它之前需要核对受影响数据。并不是新建一个字典类型就会自动在所有页面增加下拉框，它必须被字段或业务功能引用。

“允许公开 RAG 检索”允许满足条件的字典项成为 AI 公开检索来源：类型和项目都需启用，层级路径有效，并完成异步索引；勾选不代表即时完成索引。关闭或停用会触发相应来源停用。该选项管理公开 AI 检索资格，不能代替字段读写权限。

类型/项目的停用属于软停用，不是清空业务历史。单选和多选字段提交时会校验可用字典值，因此停用被引用的选项前应核对业务影响。

## 字段管理

当前支持四类业务：滑雪场、文章、动态、商家资料。先选择实体，再维护其分组及字段。字段包括稳定键、显示名、数据类型、分组、排序、默认值、校验规则、必填、可搜索、可筛选、可排序和公开标记。

数据类型包括短文本、长文本、整数、小数、布尔、日期、单选、多选及网址。单选/多选必须绑定启用的选项字典类型；其他类型不使用选项字典。默认值以 JSON 填写，例如文本 `"双板"`、数字 `100`、多选 `["parking","rental"]`；校验对象例如 `{"min":0,"max":100}` 或 `{"maxLength":100}`，按数据类型使用。

新建字段先成为草稿，启用后进入有效表单配置。启用依赖有效分组，选择类字段还依赖有效字典。已建字段的键及数据类型在编辑时保持固定。停用字段不会删除历史值，但该字段不会再作为有效字段参与正常读写。

实际读写还受角色的字段策略控制：在“角色管理”的授权页设置相应字段是否可读、可写；创建字段本身不等于赋予所有用户填写权限。“公开字段”控制公开读取资格，目前只有有效的系统管理员可将字段设为公开。可搜索/可筛选/可排序是查询能力配置，页面还需使用对应查询能力，不会自动生成所有页面的筛选控件。

## 组合使用示例

1. 在“数据字典”建立并启用“雪场设施”，维护 `parking`、`rental` 等选项。
2. 在“字段管理”选择“滑雪场”，建立有效分组，添加 `facilities` 多选字段，并绑定 `resort_facility`。
3. 核对必填、默认值、公开设置及角色字段读写权限，再启用字段。
4. 在有权限的雪场编辑表单中，为具体雪场选择设施并保存；公开展示还需该雪场自身满足发布等公开条件。

本例没有向正式环境新增配置或业务内容。
