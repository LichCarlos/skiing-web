# 管理端登录与会话生命周期

日期：2026-11-03。负责人：Web 管理端。范围：ADM-20 / API-A01 现有登录、退出及当前用户；沿用 OpenAPI 1.50.2 / 143 操作，没有新增接口、依赖、迁移或权限规则。

## 实现

逻辑留在 `apps/admin/src/platform/auth/`。`session.ts` 适配现有 Cookie API，`session-model.ts` 校验并投影响应，`AdminSessionController` 编排读取、凭证命令和生命周期，`SessionCommandGate` 记录当前浏览器 JS 环境中正在处理或结果未知的命令；Provider 连接 React。官网与 App 各自维护会话实现，共享包不保存业务身份。

移除当前用户返回 403 后强制调用 refresh 的分支。401 沿用既有 HTTP 客户端的正常刷新流程，最终 401 才转游客；403、网络失败和异常响应进入不可用状态，隐藏私有内容并允许显式核对。当前用户读取使用 no-store、AbortSignal 和单次并发，旧读取、旧按钮及旧 effect 清理不能影响后续 Provider 生命周期。

账号 trim 后小写，密码保留原文。登录沿用账号 1–50 字、密码非空且不超过 72 UTF-8 字节的现有 DTO；注册的 8 字节下限不用于旧账号登录。只采用声明的用户、角色、权限、菜单及商家字段；拒绝不完整响应。浏览器登录响应不得带原生 access/refresh token，账号与有效期必须符合契约；合法登录响应之后仍重新读取当前 Cookie 身份，退出必须确认 loggedOut=true，随后也核对当前身份。

凭证请求前同步获取门禁。网络错误、408/5xx、异常成功响应以及登录成功后身份读取失败均保留结果未知状态，禁止重复登录/退出。显式核对得到有效身份或最终 401，才能解除同一代次的保护；核对失败或命令仍在执行则保留。其他 4xx 作为明确拒绝处理，重新读取会话，不展示后端错误详情。退出失败不再无条件切换为游客。

仅会话读取失败、没有凭证命令待处理或结果未知时，登录页和路由门禁提供主动退出入口，支持账号缺少当前用户读取权限时切换账号。canSignOut 仅是本端 UI 状态，Controller 仍在派发前复核门禁；未知凭证结果时只提供会话核对，不显示退出入口。

浏览器内门禁覆盖 Provider 重建，不存储用户资料、密码、Cookie 或 Token；SSR 实例各自独立。已派发的写入继续结算门禁，卸载不把它当成取消成功，旧结果不能恢复旧身份。管理端不增加自动焦点重查，避免用户选择文件、切换窗口时卸载正在编辑的业务表单；授权最终由后端实时校验，业务页面继续沿用各自预检。

登录页还有同步提交锁，阻止 React 重绘前的重复 Enter/点击；卸载后不更新错误或跳转，跳转统一由当前已认证状态驱动。入口依据 `management:portal:enter`，不要求特定 merchant RoleKey 或商家资料；有角色/商家资料也不能替代入口权限。

## 验证与边界

新增六个测试文件 63 项，与既有管理入口 36 项合计七文件 99 项，纳入 `pnpm test:admin-auth` 及完整 check/CI。四项传输回归先对旧实现复现失败；另有一次断言子串不匹配，修正测试措辞后通过。覆盖 403、当前 Cookie 再读取、响应投影、输入、取消/单飞、旧动作、凭证并发、未知结果、恢复失败和跨 Provider 保护。页面测试使用 SSR、捕获 effect 与事件处理替身，验证重复提交、卸载错误、错误脱敏、按 grant 跳转及失败读取/未知凭证的退出入口；Provider 的真实 SSR 测试确保首帧不展示身份或发送认证请求。

这些测试不能证明真实浏览器 Cookie、自动填充、React 浏览器挂载、跨标签页、后端数据库或设备行为。内存门禁不跨刷新、标签页或设备，不提供服务端凭证命令幂等；其他标签页在途 Cookie 仍可能竞争。普通会话核对可能执行正常 refresh，不将其描述为纯 GET。没有自动重放登录或退出命令。

三仓最终完整验证与产物见共享阶段记录及各仓 README。Docker 按用户决定不重启，容器/新数据库验收保留；未重试此前被自动审批拒绝的服务启动。D-49 商家资料和 D-50 雪场原因仍等待各自确认，未在此阶段实施。
