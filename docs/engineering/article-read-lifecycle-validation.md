# 文章管理完整读取与生命周期

日期：2026-11-03。负责人：Web。沿用 OpenAPI 1.51.1 / 143 操作，不新增依赖、接口或迁移。当前结果见[本仓验证摘要](../validation/article-reads-20261103.json)。

文章列表、详情、创建/编辑表单以及写入回执均从 `unknown` 解析，只返回现有生成 VO 的公开属性。完整检查文章 ID、标题/摘要/正文、分类、封面资产字符串 ID、HTTP(S) 图片地址、作者、状态、发布时间、版本、扩展字段及创建/更新时间。草稿发布时间为 null，已发布文章必须具有发布时间；撤回沿用首次发布时间。列表核对分页、条数、重复 ID 和状态筛选；保留可选 `hasNext`，不把后续空页当成响应错误。

扩展字段目录按实体、分组、字段键和 ID 去重，核对类型、排序、布尔策略、版本及 JSON 定义，拒绝既不可读也不可写的字段。默认值保持任意合法 JSON，校验规则保持可空对象。扩展字段响应做深复制，保留 0、false、空字符串和 null；拒绝非有限数字、undefined、循环引用及非 JSON 对象。JSON 内的业务键保留，VO 外的附加属性不进入表单。

文章分类和扩展选项字典复用本端完整字典解析器，匹配请求的字典类型并检查启用状态，再迭代展开启用选项；请求失败不会交付不完整表单。字段目录比较先将两份输入投影成同一形状，避免 JSON 属性顺序造成“权限变化”的误判。

读取前后都核对身份；本地身份也必须能解析。隔离键包含账号 ID、账号名、商家资料 ID、角色和权限集合。详情读取 404 后同样复核身份，结果未知恢复仍明确提示“404 不能证明删除成功”。后端独立执行 article 数据范围与字段授权，两次身份请求不构成原子权限快照。

文章列表和编辑页隐藏或收到 `pagehide` 后，取消查询并清空文章、表单、字段目录、字典选项及封面关联；首次在后台打开也显示暂停状态，返回前台后通过显式刷新恢复。写入门禁停止准备中的命令，准备完成后再次检查共享账本，防止两个组件同时发出写入；已发送请求仍由原恢复账本跟踪，未知回执不能当成功，也不能立即重复写。恢复区域取消隐藏前的核对，生命周期代次避免旧请求结束后解锁新的核对。

发布/撤回回执要匹配原文章 ID 和预期状态；保存回执必须是完整文章 VO。DELETE 保持 204。既有接口没有客户端版本条件或创建幂等键，前端预读版本并不提供相应的并发保证。

验证入口为 `pnpm test:admin-articles` 和 `pnpm test:admin-authorization-http`。前者包含真实组件入口的模拟 Hooks/EventTarget 生命周期测试；后者用生产请求器、表单准备器和回执解析器访问编译 Nest/PostgreSQL，验证状态流转、self/selected 范围、不可见目标、读取期间撤权及软删除。后端另核对两篇文章、八条 Outbox 和八条审计。Node Cookie 适配和模拟生命周期不计实际浏览器、BFCache 或设备验收；Outbox 持久化不计 Kafka 投递。
