# 分类字段下拉选择

数据字典主操作“新增分类”按实际引用选择所属字段：文章分类对应 `knowledge.article_category`，雪场适合标签对应 `resort.fit_tag`；有字段读取权限时，追加滑雪场、文章、动态、商家资料下已启用且绑定启用字典的单选/多选扩展字段。文本等字段不作为分类目标，停用字典不可选择。选择后复核扩展字段绑定与字典状态，再进入对应字典的新增项目窗口；不会重复建立字典类型。固定字典缺失时，先配置其固定键与分组。

保留“新建选项字典”供新扩展字段使用：选择适用业务、填写可读名称，系统生成稳定的 UUID 类型键并匹配分组；之后在字段管理中绑定。类型键只读；编辑已有字典保持原键与兼容历史分组。

字段管理的单选/多选绑定改用已启用字典下拉，支持按名称/标识搜索。非选择类型不展示也不提交字典绑定，切换类型清除旧选择。分组始终使用当前实体的真实已启用分组，缺少读取权限时提示所需授权，不再接受手填引用。真正新建字段/分组的唯一标识与分类字典引用不同，仍按原后端规则维护。

字典与字段候选按全部分页读取，检查总数变化、重复项及身份权限；隐藏页面、切换账号或取消弹窗会撤销读取，失败时不发布部分候选，支持重试。复用原写入门禁、版本校验和结果未确认恢复，不新增 API、库表或数据库迁移。

验证包含完整分页与失效绑定测试，以及生产构建下桌面和手机浏览器检查。浏览器脚本 `scripts/admin-category-select-browser.mjs` 默认只读真实业务，设置本地 fixture 模式覆盖第21个扩展字段与后续字典页；所有业务写请求均拦截，避免验收写入正式配置。
