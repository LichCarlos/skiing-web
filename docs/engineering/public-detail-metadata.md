# 公开详情页分享信息

2026-11-03续验：[详情与评论边界](public-detail-validation.md)现将同一读取入口扩展为完整公开详情投影；完整VO异常也会进入元数据禁止索引分支。旧测试改用完整详情夹具，保留原36项分享断言，下方“只校验分享字段”为本阶段前的历史范围。

2026-11-03，沿用 OpenAPI 1.50.2 的公开雪场、文章、动态详情及公开配置接口。补齐页面契约 WEB-05 要求的规范链接与分享元数据，并用于知识文章和动态详情。没有新增业务 API、数据库迁移或依赖。

三个 Server Component 页面导出 `generateMetadata`，等待 Promise 路由参数；正文和元数据均经本端 `public-detail.ts` 读取既有详情接口。按 React `cache` 的请求边界复用读取，没有模块级持久缓存或用户状态。读取明确 `no-store`、`credentials: omit`、`skipAuthRefresh: true`，不转发浏览器身份；每次请求设置 10 秒取消信号并在结束后清理计时器。

分享文本包含内容标题、公开摘要和公开配置中的平台名称；名称读取失败时回退为凛迹雪客。清理控制字符和重复空白，标题最多 80 个 Unicode 码点、摘要最多 160 个，空白摘要使用对应内容的备用说明。使用 Open Graph 和 Twitter summary 文本；不将联系人、正文等额外字段写入元数据，不使用 15 分钟有效的私有资产签名 URL 作为分享图片。正文图片逻辑不变。

可选环境变量 `NEXT_PUBLIC_WEB_SITE_ORIGIN` 必须为无凭据、路径、查询和片段的 HTTP(S) origin，例如 `https://snow.example`。通过公共配置包读取，未配置时省略 canonical 和 Open Graph URL，不从请求 Host 推断。配置后由本端路由生成规范地址；动态评论分页不进入规范链接。该变量在构建时固化，变更后须重新构建，不能仅在 standalone 启动时覆盖。

非法编号在请求前进入 `notFound`；上游 404 保留该行为。其他详情读取失败或分享投影异常返回安全失败文本和 `noindex`，不暴露原始错误。显式错误的 origin 配置直接报错，便于定位部署问题。只校验分享所需字段、响应 ID 和动态已发布状态，不声称校验详情 VO 的全部字段，也不以客户端检查代替后端公开状态/字段过滤。

`pnpm test:web-metadata` 纳入 `pnpm check`。36 项测试覆盖三个路由出口、成功分享投影、无域名和非法域名、非法编号、404、异常/不匹配响应、品牌降级、空白清理、Unicode 长度及取消/计时器清理。使用 Vitest 和请求替身；不把直接函数测试视为 React RSC 请求去重或实际 Next HTML/head 验收。

实现前已查阅本仓安装的 Next.js 16.3.5 `generate-metadata.md`，遵循服务端元数据与异步参数约定。完整 check、双应用构建与文档审计以本轮阶段交付记录为准。实际浏览器、分享抓取器、Next 元数据流式输出及真实后端联调仍待验收；Docker 按用户决定不重启，也未重试此前被自动审批拒绝的服务启动。
