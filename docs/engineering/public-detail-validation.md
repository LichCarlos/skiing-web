# 官网详情、评论与公开扩展字段

日期：2026-11-03。对应 WEB-03/05/07 与 API-C01/C03/R01/K01，沿用 OpenAPI 1.50.2 / 143 操作。没有新增业务接口、授权规则、依赖、迁移或 App 平台 API。

## 修复内容

旧 `readPublicDetail` 只检查响应编号和分享投影，其他字段仍通过类型断言进入页面；null 相册、文章分类或动态图片可能在读取后的渲染阶段抛错。评论直接使用泛型响应，异常作者会破坏页面，非 visible 评论也未由前端拒绝。雪场已有的公开 customFields 没有在详情展示。八项回归先在旧实现失败，再修复对应路径。

新增本端 `public-detail-response.ts`，复用既有公开卡片投影，显式构造雪场、文章和动态的完整公开 VO。继续校验编号和分享标题；补齐相册/图片、雪况、坐标、可空文案、官网 HTTP(S) 地址、正文、更新时间及动态图片数量一致性，拒绝重复的雪场标签/动态字段键。丢弃未声明的字段与嵌套额外字段，金额字符串、签名图片 URL、合法 null/0、历史头像字符串保持原样。保留已有允许站内图片路径和无凭据 HTTP(S) 图片地址的策略。

详情正文和元数据继续使用同一个 React cache 入口，按请求复用，不建立模块级内容缓存。完整投影失败时进入现有页面错误状态，元数据禁止索引；真实上游 404 仍由页面/元数据进入 notFound，不把解析失败伪装成 404。标题/摘要/公开域名的既有生成规则保持。

新增 `readPublicComments`，在读取前验证正 int4 动态编号与正整数分页/偏移上限，再校验 page、固定 pageSize 20、非负安全 total、hasNext、最多 20 项及重复编号。只接受 visible 评论，重新构造作者/正文/时间字段；异常响应进入评论局部错误状态，保留已加载的动态与同页重试链接。合法空后续页仍可返回上一页。

评论改为复用 `readAnonymousPublic`：no-store、credentials omit、skipAuthRefresh、每请求独立 10 秒取消（覆盖响应正文），公开 401 不发起认证刷新；详情沿用同一读取策略。无自动重试，计时器在 finally 清理。取消仍依赖生产 fetch 遵守 AbortSignal，不能抢占同步解析或保证任意不遵守信号的替身按时结束。

雪场详情以现有信息栏样式展示服务端返回的公开 customFields，显示字段标签和文本值；null 显示“暂无信息”，数字 0 保留，布尔显示“是/否”，多选数组以顿号连接。React 继续按文本转义。公开性与业务授权仍由后端的 IsPublic 投影负责，前端无法从缺少定义的值项重新判定字段授权；没有把商家原始 JSON 或字段定义放到公开页面。

## 验证

新增 52 项：47 项响应/组合页面回归和 5 项真实 Node HTTP/fetch 合成 API 测试。覆盖八项原问题、完整 VO 异常、来源编号不匹配、分页/重复项、未知字段裁剪、精确金额/签名 URL、公开字段零值/布尔/多选显示、元数据失败索引，以及公开 401 无认证请求、404 保留、错误分区和停滞评论正文 10 秒取消并关闭连接。与既有目录、首页、元数据及社区测试合计 11 文件 244 项通过，纳入既有 test:web-community 和完整 check；类型检查和变更文件 ESLint 通过。

既有元数据测试由只含分享字段的替身更新为完整公开详情夹具，原标题/摘要/域名/错误断言保持。评论成功夹具原先 page=2/pageSize=20/total=23 却声明 hasNext=true，现改为 total=43，继续验证双向分页；未放宽新的分页一致性要求。旧评论请求断言增加匿名、禁止刷新和取消信号的精确检查。
