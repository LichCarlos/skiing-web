## 登录页最新澄清

本节替代此前“图片固定左侧、按钮在表单顶部”的解释。电脑端登录左图右表单，注册左表单右图；照片始终40%、表单60%，用transform平滑互换，不重挂载照片。卡片上限1080×680并受可用视口约束，同视口各状态尺寸相同。中央48px按钮独立绝对定位在整张卡片中心，切换时坐标不变，采用用户提供的1024 viewBox双箭头SVG；登录蓝底、注册白底。

中央按钮两侧留出空间，避免遮挡输入。手机隐藏照片、表单占满卡片；按钮固定顶部中央，不放在手机输入区域中央。减少动效时取消平移动画，保留正确布局和交互。

注册新增必填确认密码，按原始字符串比较，不trim或改变密码。两次不一致时显示错误并聚焦确认框，不能发送请求；一致才调用现有RegistrationRun，不把确认密码发送给后端。提交后清空两个密码输入，切换模式也清空。注册成功保留账号、回登录、提示手动登录，不自动创建会话。后端DTO/API/权限规则未变。
