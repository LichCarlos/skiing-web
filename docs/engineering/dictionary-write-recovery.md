字典类型和字典项使用同一账号级写入记录。`dictionary-recovery.ts` 在当前标签页内存中保存账号、目标字典键、是否仍在请求中及操作令牌，不保存表单、响应或凭证。一个账号同时只允许一个字典写入，列表与不同详情组件重挂载后继续受限制；其他账号独立。服务端成功或明确4xx拒绝后清除该次记录，408、5xx及网络失败保留未知状态。组件销毁后迟到的响应仍维护记录，但不更新旧页面。

未知结果必须在原目标字典核对。目录重挂载可恢复该目标，在其他详情页则提供前往原字典的链接。刷新核对同时读取列表及目标详情；详情模式读取目标，确认404之前也需再次核实身份。请求进行中不能人工清除；核对成功后操作者显式确认，期间任何记录版本变化都会要求重新核对。不会自动重放命令，旧请求令牌和旧核对版本不能清除新操作。

`dictionary-queries.ts` 对读取前后的 `/auth/me` 响应使用本端会话解析器，比较账号、角色和grants，所有读取传递取消信号并使用no-store。列表校验分页、hasNext、条数、重复类型和筛选条件；详情核对精确类型键。类型/项目响应按现有VO逐字段投影，验证项目ID、父子关系、重复ID、状态与标量类型，移除额外属性。客户端复核之后仍可能发生身份变化，后端是最终授权依据。

树解析、表格展开和父级选项采用迭代遍历，避免深层合法树耗尽调用栈；父级选项继续排除自身及后代，展示缩进最多24级，真实层级和提交parentId不变。测试包含6000层树，这不是新增后端深度承诺。

`pnpm test:admin-dictionaries` 现为115项，较原68项新增47项；初次新增回归复现7项失败后修复。覆盖组件重挂载/销毁、请求前并发竞争、明确拒绝/未知结果、旧令牌/核对版本、账号/角色/grants变化、响应投影、树结构及取消。页面接线使用同步SSR和模拟客户端快照测试，不证明实际浏览器hydration或导航。

字典与字段页均以 `useSyncExternalStore` 返回的版本决定何时读取浏览器记录；服务端及首次hydration快照为0，此时使用空恢复状态。避免一边订阅服务端快照、一边直接读取浏览器内存而产生不同的首屏。两项SSR回归先失败后修复；客户端快照接线由测试替身验证，真实hydration仍待浏览器验收。

独立 `pnpm test:admin-authorization-http` 新增生产字典分页/详情读取器一项，配合后端专用临时库的父子项目（含disabled子项）。现行套件十一项，含此前十项；生产HTTP入口和执行方式见[真实授权联调](admin-authorization-live-http.md)。后端夹具直接准备合成记录，不代替字典业务写入API验收，也不代表本轮新增数据库业务覆盖。

恢复记录不跨刷新、浏览器关闭、标签页或设备，不增加服务端幂等键、乐观锁或跨端共享状态。Browser/Next生产服务、Expo、容器和设备验收仍以共享阶段记录为准。
