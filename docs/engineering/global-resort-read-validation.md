# 全局雪场完整读取与生命周期验证

日期：2026-11-03。对应 ADM-13 / API-M05，沿用 OpenAPI 1.51.1 的既有协议。本轮未新增接口、DTO 字段或迁移。

列表、详情及保存/发布/下架回执由 `global-resort-responses.ts` 从 unknown 解析。公共资料复用商家雪场完整解析器，额外校验商家编号/名称、标签对象和动态字段数组；拒绝重复键、非法数值与不符合既有联合类型的字段值。输出只投影 VO 字段并复制数组，保留 bigint 资产编号与十进制字符串精度。分页核对页码、每页20条、总数、实际条数、hasNext、重复目标及商家/状态筛选一致性。

读取前验证本地身份，读取前后请求 `/auth/me` 并核对账号、角色、grants 与商家关联；404 核对也包含结束身份检查。表单解析完整字段目录与字典，确保类型/启用状态匹配，所需可写字段选项加载失败时禁止保存。保存前对原目标和解析后的字段策略重新核对，避免 JSON 属性顺序产生误报。身份复核不构成跨请求原子快照，服务端独立执行授权。

列表、表单和恢复面板在隐藏/pagehide 时取消读取并清除数据；返回后需要显式读取。首次后台打开不读取。表单同时清除字段、图片预览和未保存内容，取消上传，阻止旧 finally 解锁新请求；隐藏后媒体组件卸载。写入门禁验证本地身份、按具体动作复核远程身份，并在准备完成后仲裁共享账本。已发送而结果未知的请求保留人工核对记录，不自动重放；恢复面板用代次阻止旧异步任务解除新核对的锁。

真实 HTTP 续验使用生产读取/保存/状态命令函数、编译 Nest 和独立临时 PostgreSQL：可配置角色创建/发布、字段目录过滤和私有字段越权拒绝、管理员编辑评分并改归属、已发布编辑保持发布、下架/再发布、原商家404、错误范围403、实际响应期间撤权以及软删除。后置数据库核对见[后端说明](../../../backend/docs/engineering/global-resort-http-validation.md)，最终结果与日志哈希见[本仓证据](../validation/global-resort-reads-20261103.json)。

测试中的 Hooks/EventTarget 为模拟生命周期，Node Cookie 适配用于真实 HTTP；这些均不能证明浏览器 React、BFCache 或设备行为。现有雪场请求不含客户端版本前置条件或创建幂等键，其他标签页/设备及商家入口之间不共享前端账本。图片实际存储、Kafka 投递、真实供应商、容器、签名原生包和远程 CI 仍待验。D-49 / D-50 / D-09 保持待决，整套项目未完成；本轮未启动或重启 Docker。
