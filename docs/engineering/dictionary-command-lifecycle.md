# 字典管理回执与页面生命周期

日期：2026-11-03。负责人：Web。对应 ADM-10、API-M09。沿用 OpenAPI 1.51.1 / 143 操作，无接口、授权、版本或数据库迁移变更。

字典类型的创建和编辑复用完整 DictionaryTypeVO 解析；字典项保存校验完整 DictionaryItemVO、目标编号、已提交父级及其子树。根节点可以属于已有父级，但不能把父级再次放入自己的子树，也不能包含重复编号、父子不匹配或非法状态。响应只保留契约字段。停用类型和字典项必须收到空响应。异常成功回执进入待核对状态，不再显示保存成功或自动重复提交。

列表与详情在请求前校验本地身份，再读取当前身份，结束时再次核对。身份隔离包含账号、用户编号、商家关联、角色键和 grants；不依赖固定商家角色。写入门禁在准备表单前检查本地身份，提交前校验最新动作权限，并通过同标签页账本阻止重复写入。未确认结果跨页面重挂载保留目标键，人工刷新后才能解除阻断。

隐藏、pagehide 和卸载取消列表及详情读取，隐藏时清除数据、编辑表单和弹窗，停用写入门禁。首次后台打开也暂停读取。返回前台后通过“刷新字典”或待核对入口显式恢复，旧响应不能重新填入数据。列表按查询键隐藏旧筛选结果；人工核对使用代次隔离，旧核对的 finally 不能解锁新操作。

专项包括完整回执、非根子树、自身或祖先循环、异常成功响应保留账本、账号/商家变化、本地身份拒绝，以及模拟 Hooks/EventTarget 的列表和详情取消/初始隐藏。首次专用类型检查发现测试替身缺少泛型调用签名，修正后复查通过，失败日志保留。最终测试数和三仓验证以[本仓报告](../validation/dictionary-workflow-20261103.json)为准。

真实管理 HTTP 直接使用上述生产命令和门禁，连接编译 Nest 和临时 PostgreSQL：可配置角色建类型/父项/子项、更新、循环拒绝、子项停用、类型公开标记与停用、筛选及后续空页；另在实际读取期间撤销角色授权，结束身份校验拒绝旧响应。[数据库核对](../../../backend/docs/engineering/dictionary-workflow-http.md)检查最终层级、状态和同事务审计/Outbox。临时数据库全部为合成数据。

前后身份检查不构成跨请求原子快照；现有字典命令没有新增客户端版本或幂等协议。模拟生命周期及 Node Cookie 不能证明真实 React、浏览器、BFCache 或设备验收；pending Outbox 不能证明 Kafka 投递和 RAG 重建。真实供应商、生产存储、Kafka/容器、签名包及远程 CI 仍待验收；D-49/D-50/D-09 未实施，整个项目尚未完成。
