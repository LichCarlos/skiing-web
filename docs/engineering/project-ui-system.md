# 官网、管理端与移动端 UI 优化

最新主题要求已改为冰蓝/白，取代此前绿色/橙色与后台紫色。核心色值见两应用 DESIGN.md；新色板的双构建、3052 项测试、35 个浏览器状态及对比度见[主题复验](../validation/ice-theme-20261105.json)。下文首次优化的计数保留为历史记录。

## Web 实现

官网提取 `SiteNavigation`，覆盖首页、雪场/知识/动态目录及详情，统一当前栏目和手机两行导航；移除重复页脚与无业务意义的英文标题装饰。原海岸首页配图替换为已核对的雪景，按最新要求统一为浅蓝/白主题；官网、管理端和 App 使用同一核心色板。

主题、全局焦点、选中文字、输入光标、禁用态及减少动画规则集中维护。目录筛选、公开字段查询、登录展开面板、卡片、详情正文与空状态调整了对比度、圆角、阅读宽度和触控尺寸。公开字段查询页补齐页面留白和导航。

管理端沿用本日已完成的 Ant Design 主题、分组侧栏、手机抽屉、表格、表单、弹窗、登录与工作台优化，详见[管理端规范](../../apps/admin/DESIGN.md)及[管理端验证](../validation/admin-ui-20261105.json)。本轮未再次修改其业务权限。

## 组件库选择

| 使用场景 | 当前选择                              | 适用原因                                         |
| -------- | ------------------------------------- | ------------------------------------------------ |
| 管理后台 | Ant Design                            | 表格、树、复杂表单、授权和弹窗已有成熟能力       |
| 官网     | CSS Modules + 现有 Base UI/shadcn     | 保留品牌排版，按需提供可访问交互                 |
| Expo App | React Native 原生组件 + 本仓主题/控件 | 符合现有代码与跨平台体系，不额外引入一套样式系统 |

本轮没有新增第三方 UI 依赖。移动端规范和源码由独立 App 仓库维护，Web 不跨仓导入。
