# 媒体管理完整读取与生命周期验证

日期：2026-11-03。对应 ADM-17 / API-ASSET-02，沿用 OpenAPI 1.51.1 / 143 操作，不新增接口、字段、授权协议或迁移。

媒体列表和详情从 unknown 解析完整 AdminAssetVO。复用图片库的资产投影，校验 BigInt 字符串、上传者、大小、状态、日期、HTTP(S) 无凭证 URL 和五类非负引用数；复制引用对象，不保留 storageKey、哈希及额外响应字段。管理分页固定20条，检查目标页、总数、实际条数、hasNext、重复编号及状态/上传者筛选。DELETE 只接受空响应，异常回执保留未知结果核对要求。

读取前先验证本地身份，再通过 /auth/me 核对，读取结束后复核账号、商家关联、角色和 grants。404 核对也不能绕过结束身份检查。列表按筛选键隐藏旧结果；列表和详情在 hidden/pagehide 时取消读取、清除私有预览/目标弹窗与输入，返回后显式刷新，首次后台打开不读取。写门禁在准备前核对身份，发送前以共享账本仲裁；已发送而结果未知的记录跨重挂载保留，不自动重放。恢复面板以代次保护旧 finally。

真实生产 HTTP 使用已编译 Nest 和独立 PostgreSQL，验证配置角色的 self/all/selected 范围、外部目标404、merchant范围403、后续空页、上传者/状态/关键词筛选、900秒签名参数及原始响应白名单；头像引用的停用422和解除关联、未引用媒体软删除与 retained inventory，以及实际读取期间撤权。最终结果见[本仓证据](../validation/asset-admin-reads-20261103.json)与[后端持久核对](../../../backend/docs/engineering/asset-admin-http-validation.md)。
