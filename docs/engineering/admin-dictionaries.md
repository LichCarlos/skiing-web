## 列表与详情

[字典列表](../../apps/admin/src/app/admin/system/dictionaries/page.tsx) 和独立详情路由装配同一个 [DictionaryConsole](../../apps/admin/src/features/dictionaries/dictionary-console.tsx)。列表“字典项”为原生 Next Link，可直达 `/admin/system/dictionaries/[dictType]`；详情提供固定返回列表入口，列表双击仍可快捷预览。详情按 URL 类型键加载，跳转到其他类型时重建页面实例；直达详情不请求类型列表。类型列表只依赖分组、状态、页码及显式刷新次数；详情通过现有 `GET /admin/dictionaries/:dictType` 独立读取，不以响应对象作为列表依赖。切换列表筛选或页码会收起预览。

[路由目录](../../apps/admin/src/features/dictionaries/routes.ts) 集中声明路径、链接构造与键校验。详情 Server Component 等待 Promise params，按后端的小写 ASCII 类型键规则验证长度及字符集，非法键 notFound；路径权限判断解码一次后使用同一规则，拒绝嵌套路径、编码斜线、双重编码及非法百分号。入口仍要求管理入口与字典 list grant，不依赖业务角色名称。详情可展示分组、状态、公开 RAG 标记和项数，按动作权限编辑类型或维护字典项；停用类型后保留当前 URL 并重新读取。

[业务模型](../../apps/admin/src/features/dictionaries/dictionary-model.ts) 为列表、详情分别提供读取通道。发起下一次读取或关闭页面时取消上一次；即使底层忽略 AbortSignal，迟到的成功、错误和结束回调也不会发布到当前页面。列表与详情各有加载、失败和重试状态，详情读取失败仍保留类型键和重试入口。旧筛选列表在新请求开始时清除。

## 层级表单与 DTO

列表表格使用拍平后不含 children 的 ItemRow，保留 depth 进行缩进，每个字典项只显示一次。编辑父级时排除当前节点及其整棵子树。清空父级明确提交 `parentId: null`，空颜色提交 `color: null`；类型和字典项表单从本仓生成的 create/update DTO 派生，字典项写入仅投影 DTO 字段。后端同类型、父级存在和祖先环校验继续生效，前端选择项不代替事务校验。

## 权限与写入

账号 ID 与排序后的有效 permissionKeys 组成页面实例键，账号或权限快照改变时卸载旧表单、取消读取与写入回调。入口要求 management:portal:enter 和 system:dict:list，新增、编辑、停用分别按 create/update/delete grant 控制；不检查商家或其他业务角色键。

写入门禁在异步表单校验开始前同步加锁，覆盖校验、GET /auth/me 核对与写请求。核对当前账号及入口、列表和动作权限后才提交；期间禁用表单与切换操作。卸载后的校验/身份结果不会继续提交，迟到写响应不刷新新账号页面。后端仍是最终授权边界，跨标签 Cookie 同时变化不能仅靠前端消除。

网络中断、408 或 5xx 无法证明写入未发生，页面关闭旧表单并暂停再次写入；用户点击“刷新核对”，成功读取列表和当前详情后才能显式确认继续。详情明确 404 也可核对，避免已停用类型的响应丢失后无法恢复；401/403、网络失败不会被视为核对成功。应用层不自动重发写入，现有统一请求层的确定性认证/CSRF 恢复规则不变。此门禁作用于当前页面，不提供跨设备幂等保证。
