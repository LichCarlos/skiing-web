# 社区审核读取与生命周期验证

日期：2026-11-03。对应 ADM-16 / API-M08，沿用 OpenAPI 1.51.1 / 143 操作，不新增接口、请求字段或迁移。

动态详情/列表和评论分页由 `moderation-responses.ts` 从 unknown 解析并投影现有 VO。检查编号、状态、日期、图片 URL、审核元数据、父动态归属、重复目标、实际条数、总数、hasNext 和状态筛选；复制图片数组，忽略响应中非契约字段。审核命令使用独立的 DynamicModerationVO / CommentModerationVO，校验目标、结果状态和三项可空审核元数据，DELETE 仅接受空响应。没有将精简回执误当作完整动态详情。

本地身份先解析，读取前后请求 `/auth/me`，比较账号、商家关联、角色和 grants；404 的人工核对同样复核结束身份。页面按账号和目标重建；列表和评论页参数变化时立即隐藏旧页，隐藏/pagehide 取消在途读取、清除资料/评论/原因弹窗，返回后显式刷新。首次后台打开暂停。写门禁增加本地身份校验与共享账本仲裁，防止两个准备中的入口重复发送；恢复面板通过代次隔离旧异步 finally。已发送而结果未知的写入保留原记录，不自动重放。

新增40项测试，社区专项132项，含29项先在旧代码全部失败的边界测试。旧查询夹具缺少合法分页、读取后身份及完整命令回执，首轮114通过/7失败；补齐夹具后127通过，再补身份关联、评论分页和门禁并发后132通过。生命周期使用模拟 Hooks/EventTarget，不计真实 React/浏览器/BFCache 验收。

生产客户端真实 HTTP 覆盖普通配置角色创建并批准动态、已发布编辑转 pending 并从公开查询隐藏、管理员复审/隐藏/恢复；评论创建、隐藏/恢复/重复恢复409和软删除；实际读取期间撤权以及动态软删除。最终测试数、三仓检查和产物哈希见[本仓证据](../validation/community-reads-20261103.json)，持久核对见[后端说明](../../../backend/docs/engineering/community-moderation-http-validation.md)。

身份前后检查不是跨请求原子权限快照；既有命令没有客户端 expectedVersion 或幂等键，预读和实际提交间仍有竞争窗口。签名图片 URL 不纳入内容指纹。社区资源数据范围尚未定版，本轮不擅自新增过滤协议。Node Cookie 适配不能代替浏览器；Outbox 持久化不能证明 Kafka 投递。真实浏览器/设备、供应商/存储、Kafka、容器/签名包及远程 CI 仍待验，D-49 / D-50 / D-09 保持待决，整套项目未完成，Docker 未启动/重启。
