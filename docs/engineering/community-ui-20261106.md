后续发布：2026-11-06 17:55官网部分已包含在[官网登录页与体验更新](public-auth-release-20261106.md)中。后台/App增量未由该轮发布；下述12项本地fixture/合成相册验收不能改称生产验收。

## 范围与并行工作保护

本轮按“独立登录页 → 首页主视觉 → 目录导航 → 雪场相册与社区 → App 原生反馈 → 后台轻修”检查工作区。检查时独立 `/login`、注册页内切换、Waves 蓝底红线、实景照片和 Cookie 会话接入已经存在，属主对话正在完成的改动；本轮保留，不重新实现或覆盖。既有认证、权限、内容状态、DTO/VO、数据库和线上数据没有修改。

本轮仅本地实现，没有部署、发布 APK、提交或推送。前期复用主对话的 `http://127.0.0.1:3210/snow` 只读预览，不停止该进程。尝试启动另一开发服务被 Next 并发保护拒绝后，没有删除锁文件或结束原服务。主对话随后自行结束原预览；最终通过本轮自有临时 Next 服务4312和只读空数据API fixture4314复验，验证后关闭自己的服务。未调用生产API或认证写入。

## 实际改动

| 区域     | 已实现                                                                   | 保留边界                                                                         |
| -------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| 首页     | 标题按短语分行有限入场，48 个纯 CSS 像素块一次揭幕，桌面雪场封面轻缩放   | 不加入持续 RAF/WebGL、GSAP/Motion 依赖；旧氛围图及“非雪场实拍”说明保留           |
| 导航目录 | 在原生 dialog 内逐项错峰进入，悬停/焦点箭头反馈，获得焦点时取消入场隐藏  | 保留 Escape、Tab 循环、焦点归还、Next 路由及移动布局；不接管全局滚轮             |
| 雪场相册 | 全部相册图片原生横滑，张数、前后按钮、点击大图                           | 仅使用公开详情已有的 URL，不新增资产查询或扩大权限                               |
| 社区相册 | 与雪场共用官网内的 `PhotoGallery`                                        | 不改变动态分页、审核或主要关联雪场                                               |
| 大图浏览 | 原生 dialog、方向键、Tab 循环、Escape/关闭归还焦点、背景滚动锁及卸载恢复 | 无自动轮播；原生手势横滑用于底层相册，弹窗使用按钮/键盘，不宣称弹窗支持捏合/拖拽 |
| 图片失效 | 读取失败显示说明，用户可显式重新读取页面，重新请求公开投影 URL           | 不将签名 URL 持久化；不在前端伪造续签、抓任意外链或改变资产权限                  |
| 社区卡片 | 已关联雪场名称变为真实站内详情链接                                       | 无关联时保持“雪友分享”，不做名称模糊匹配                                         |
| 管理端   | 工作台入口焦点背景/描边、数值换行、减少动画适配                          | 不动画化金额或替换 Ant Design 的表单/表格/权限树                                 |

`PhotoGallery` 由本项目实现，并非复制 React Bits Carousel；标题、像素揭幕和目录同样是轻量自有实现。主对话已引入的 Waves 源码及许可证位于 `apps/web/src/features/auth/vendor`。不要把本轮描述为安装了整个 React Bits 库。

## 方案取舍与来源

参考 [React Bits](https://github.com/DavidHDev/react-bits) 的 SplitText、PixelTransition、StaggeredMenu、Carousel 和 Waves 思路，但按真实成本取舍：本项目标题只有两行，不必为其引入 GSAP；相册需要阅读顺序/键盘/SSR，不采用 3D 环形画廊；现有雪场纵滚横移已经具备降级，不替换为 ScrollStack。

2026-11-06 核查的上游最新提交为 `4dc7b5b7772e1217c8fb8d2a7aa074302180e5b4`，官方当前许可证是 **MIT + Commons Clause**，允许应用集成但对组件/工具/导出物作为独立产品转售或再分发有限制，不应标为纯 MIT。当前 Waves 使用 WebGL2；地图 Topography 只是装饰，不能替代真实地图。

- 当前本地公开数据是空集，没有为截图造生产内容。相册交互另以**真实 PhotoGallery 组件＋隔离 Vite 页面＋替代 next/image＋合成 SVG**检查按钮、原生滚动、大图、键盘和失败恢复，不能冒充真实雪场/签名资产完整端到端验收。
- 图片错误恢复测试是主动派发非冒泡错误事件验证 UI，不等于实际等待 15 分钟签名过期。关闭dialog后的React effect清理由浏览器等待条件确认，不能将异步卸载断言写成即时读取。
- 本轮未执行新生产构建、线上切换、真实登录提交或真实资产写入。Android/iOS 原生及图片权限未由网页替代验收。

- Playwright 默认浏览器缓存缺失，复用已安装 Edge；未下载新浏览器。测试结束只关闭自己创建的浏览器/Vite 服务，保留主对话 Next 进程。
