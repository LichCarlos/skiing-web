# 系统配置完整读取与保存恢复

日期：2026-11-03。负责人：Web。对应 ADM-21 / API-M11，沿用 OpenAPI 1.51.1 / 143操作与六项文本目录，不增加接口、权限、配置键或迁移。

管理目录、编辑器及保存回执从 unknown 解析完整 SystemConfigVO。校验白名单键、文本类型、每键长度、可空默认值/内容、非负Int版本、可空时间和更新人编号，返回九个固定字段。目录核对请求页/页大小、总数不超过六项、条数、hasNext、重复键及名称/键筛选。按既有列表查询精确定位编辑目标，不新增 GET/:key。

读取前校验本地身份，再访问 /auth/me；响应解析后复核身份。隔离键包含用户编号、账号、商家关联、角色和 grants。保持 system_admin 与配置 list/update 的既有保护，普通账号持有相同 grants 仍不能管理系统配置。客户端身份检查不是跨请求原子授权快照，服务端继续负责最终授权。

列表按查询键隐藏旧页，隐藏/pagehide 时取消读取、关闭编辑器并清空内容与搜索。编辑器隐藏时清空正文和配置原本，迟到成功/错误不能回填；首次后台打开暂停，返回后通过明确刷新恢复。提交门禁在准备表单前检查本地权限，在发送前再次检查共享账本，阻止两个已完成预读的页面实例重复提交。核对面板的代次保护防止旧 finally 释放新核对。

保存继续提交原始 expectedVersion，不静默重取版本覆盖；回执验证完整VO、目标、version+1及规范化内容。409保留修改并要求显式刷新，畸形成功回执或网络结果未知保留账号级待核对键，不自动重放。后台/卸载后的旧保存回调不再提示成功或更新新页面。
