1. 新目录独立准备和校验，旧版继续运行。
2. 以 `linji` 用户在回环端口 13200/13201 启动临时候选服务，检查首页、登录页、主视觉和主题标记。

4. 重启这两个前端服务，检查正式回环页面、服务状态与真实 HTTPS 页面；候选/构建进程均已停止。
5. 记录切换前后服务 PID 和配置哈希：其他 29 个运行服务 PID/状态未变，API PID 仍为 1431609，API unit 与 Nginx 主配置哈希未变。未做数据库迁移、业务数据写入或权限调整。

切换脚本带失败自动恢复；本次切换成功，未执行回滚。需手工回滚时在服务器运行：

```bash
bash /opt/linji/releases/20261106-ui/rollback-server.sh
```

该脚本先验证当前路径确为本次版本，再恢复两个已备份 unit 并重启；不删除新旧版本，不动后端或 Nginx。回滚后的 HTTPS 仍需重新验收。
