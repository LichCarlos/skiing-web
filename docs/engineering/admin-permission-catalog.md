## 页面与数据

路由保留 Server Component 外壳，交互位于 `features/permissions/catalog-console.tsx`；按已安装 Next.js 16.3.5 的 `use-client`、Server/Client Components 文档实现。DTO/VO 直接使用本仓 OpenAPI 生成类型，不跨仓导入代码。

原页面递归拍平的行仍包含 `children`，Ant Design Table 会再次作为树展开，造成重复行。现在迭代拍平并去掉 children，仅保留深度和子节点数，稳定先序显示，每个节点一行。重复 ID/环使该次读取失败，不以损坏目录渲染表格。活动父级按 directory→menu→button 匹配，排除自身及最新详情中的后代；根目录显式 parentId=null。列表与节点详情分别由 RequestLane 管理，取消后抑制迟到成功、失败和 finally。

编辑先读取既有单节点详情，拒绝已变为 API 的节点；表单重置后填入最新元数据。创建/编辑工厂仅输出 DTO 白名单，更新不发送唯一键、类型或来源；支持文本 trim、路由/图标显式 null、0 排序与 false 可见性。菜单非空路由要求 `/` 开头。非菜单路由也展示和保存，避免原页面隐藏字段被无意清空。系统来源节点和目录不提供停用状态编辑，API 节点仅通过注册表同步维护；自定义菜单/按钮允许已有状态操作。后端继续独立校验角色引用及层级，前端不推断未知的引用数量。

## 会话与写入

入口要求有效会话、管理入口和 `system:permission:list`，自定义角色按 grants 工作。创建、更新、停用按钮各自检查动作 grant；同步还要求当前身份含 system_admin 且具备 update grant。初始/重试列表读取先确认 `/auth/me` 账号和读取权限。账号、grants、角色键变化使工作区重新挂载，丢弃旧数据和编辑上下文。

CatalogWriteGate 在异步表单校验前同步加锁；详情预读也位于该锁内。提交前重新读取当前身份，核对账号、管理入口、列表/动作授权及同步管理员能力。卸载取消请求并抑制旧回调；没有自动重放写入。前端检查用于工作流保护，权限最终由后端事务决定，不能中断已到达服务端的操作。

明确的 HTTP 4xx（408 除外）允许修改后重试。网络/408/5xx 写入结果无法确认时，关闭弹窗并阻止后续写入，先刷新当前目录，再由用户确认核对。详情预读失败不标记为写入不确定。恢复弹窗不会挡住核对按钮。写入前在本功能的浏览器内存台账登记每次操作的独立标记；确认成功或明确拒绝仅清除该操作，未知结果保留。守卫卸载页面后，新工作区仍读取该账号的未确认标记并阻止重放；旧操作的迟到结果不能清除核对后新建操作的标记。卸载后不执行页面回调，仅按原账号/操作更新内存标记。SSR 不分配、不读取或修改浏览器台账。

未确认标记保存在当前浏览器运行实例的功能内存中，不持久化到 localStorage/Cookie，不保存凭证或业务内容；账号之间隔离，核对后仅清除本人标记。支持守卫卸载和同一运行实例内的重新挂载，不承诺跨完整页面重载、其他标签页或设备保留，也没有新增服务端幂等键。同步结果仍需按实际元数据与审计核对；本轮不宣称端到端幂等。

## 验证范围

权限专项由 `test:admin-permissions` 扫描整个功能目录。新模型/门禁测试与页面 SSR 测试，连同原 PermissionTreeView 测试共 72 项，覆盖去重/树损坏拒绝、活动父级、DTO 白名单/清空/保护字段、动作授权、账号切换、防重入、不确定结果阻止重放、身份重载/守卫重挂载恢复、在途操作标记隔离及卸载回调。SSR 验证加载/匿名/无权入口、可配置角色及同步控件授权，不证明浏览器挂载后的网络或点击过程。

初轮类型检查发现数组索引需显式非空断言；专项初轮 10 项失败来自测试 ApiError 夹具构造方式与共享类不符，后续类型检查又发现测试 code 必须为数字，均按共享客户端签名修正。客户端生产协议未修改。完整三仓回归与构建结果记录于本仓 README 和中央测试现状。

保留各仓 `permission-console-*.log` 与 App `dist-permission-console-validation/`。真实浏览器/API 成功数据工作流、设备及真实供应商验收仍待完成；项目整体未完成。
