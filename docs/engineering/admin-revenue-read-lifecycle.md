# 收益维护完整读取与页面恢复

日期：2026-11-03。负责人：Web。对应 ADM-24 / API-R04，继续采用 OpenAPI 1.51.1 / 143 操作，不新增接口、权限、数据库字段或幂等规则。

收益列表从不可信响应投影十项公开字段，并单独投影录入人的 userId/nickname。校验 int4 编号、定点金额字符串、实际日期、时间、来源、可空备注、完整分页、重复编号和雪场/日期筛选匹配。查询在第一次 await 前复制，只接受现有参数；拒绝重复或未知参数，避免调用方在身份核对期间修改查询。保留未填写起止日期的查询和后续空页。

页面增加可见性边界。初始页面待挂载后才读取，后台打开暂停；隐藏或 pagehide 立即中止页面信号，卸载列表、筛选、单条表单与导入面板。返回后显式核对当前身份再创建新页面。账号、商家关联、角色和 grants 变化仍通过既有隔离键重挂载；读取前后继续复核身份。查询键在切换条件的首帧隐藏旧列表。

单条保存/核对与 CSV 上传/查询接收页面信号。隐藏发生在身份核对期间时不继续发送；已发请求取消后保留原 UUID、DTO、文件和未知结果状态，不自动生成新键。若取消后收到已知 CSV 任务回执，恢复层保留任务编号供后续查询，旧页面不再显示回执或错误。已有 sessionStorage/IndexedDB 恢复存储不随页面卸载清除，仍由用户主动核对和确认结束。

CSV 选文件在读取字节前加同步锁，防止两次选择同时创建恢复记录。原恢复存储读取失败时禁止选择新文件；字节读取期间取消则不新增本机记录。只读账号不初始化 CSV 恢复存储。

本轮运行结果以[验证报告](../validation/admin-revenue-20261103.json)为准。新增读取边界、取消、文件竞争和模拟可见性测试；隔离真实 HTTP 在原收益八项恢复场景上补充完整字段/筛选/后续空页和读取中真实退出会话两项，并保留数据库后置核对。后端生产逻辑和迁移没有变化。

Hooks/EventTarget 和 Node Cookie 为测试适配，不能证明实际 React、浏览器/BFCache 或设备行为；CSV 恢复由原应用服务显式执行，未证明 Kafka、Inbox、定时器或租约到期。三仓当前检查、构建/导出及服务清理结果见报告。真实浏览器/设备、模型/Embedding、生产存储、Kafka/容器、签名包和远程 CI 仍待验，D-49/D-50/D-09 未实施，项目整体未完成。
