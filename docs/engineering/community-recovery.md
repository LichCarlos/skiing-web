## 信息流

`features/community/feed-query.ts` 处理白名单输入、编码、加载状态与链接，`feed-directory.tsx` 渲染目录，路由页面只负责装配。关键词最长 200 字符，游标长度与字符集预先检查；客户端保留不透明游标，服务端校验其内容。

失败重试保留搜索词和游标；“返回最新动态”只移除游标，保留搜索词。原生 GET 搜索从最新一页开始。下一页仅使用服务端 nextCursor，同时要求 hasNext；后续空页可回到同一关键词的最新动态。“已到末尾”不再错误显示为“已到最新”。未知身份/审核字段不向公开接口转发。

## 详情与评论

动态和雪场详情在调用 API 前拒绝非正 int4 路由 ID，并通过 notFound 呈现缺失页面；真实 404 同样映射为 notFound，其他服务失败保留重试。评论页码和偏移先校验；错误只影响评论区域，不丢弃已加载动态。评论失败重试保留当前页；空的后续评论页提供上一页入口，不把它说成整条动态“还没有评论”。正文、昵称和评论继续由 React 文本转义。
