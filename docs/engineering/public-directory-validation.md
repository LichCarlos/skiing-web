# 官网公开列表响应与请求边界

日期：2026-11-03。对应 WEB-02/04/06、API-C01/R01/K01，消费本仓 OpenAPI 1.50.2 / 143 操作。没有新增业务接口、权限、依赖、数据库迁移或 App 平台 API。

## 实现

原雪场、知识文章和社区列表直接使用泛型响应，畸形记录、地区、分类或分页仍可能进入视图并导致渲染失败；额外字段留在服务端页面数据中。原读取只有 no-store，没有超时和显式的匿名/禁止认证刷新选项。七项回归先在旧代码复现失败，再修复对应路径。

三个列表及雪场适配标签、知识分类目录统一通过本端 `features/public-content/public-read.ts` 读取：no-store、credentials omit、skipAuthRefresh，单次请求 10 秒取消，包含响应头之后尚未结束的正文。每次调用有独立 AbortController 和计时器，finally 清理；响应若晚于取消返回仍拒绝使用。不建立模块级数据缓存，不自动重试。公开 401 降级到现有错误状态，不调用 refresh 或 CSRF 接口；用户文章收藏继续由既有客户端会话和独立读取负责。

公开卡片校验从首页提取到 `public-card-response.ts`，首页保留原有三项上限和入口；三个目录复用同一份雪场、文章、动态公开投影。只构造 VO 声明字段，嵌套地区、分类、作者及动态字段也重新投影；拒绝 null、重复编号、非正 int4、异常金额/评分/距离/时间和非 published 动态。金额保留十进制文本，签名图片 URL 原样保留，合法 null、0 和历史头像字符串兼容规则保持。

`public-directory-response.ts` 对偏移分页核对请求页码、固定 pageSize 12、非负安全整数 total、hasNext 及最多 12 项；总数取服务端，允许合法空后续页，不要求当前页条数等于分页理论值。游标信息流校验最多 12 项和 hasNext/nextCursor 组合；下一页不能为空、格式错误或等于当前游标，不解码或自行构造服务端游标。标签和分类只投影 value/label，拒绝重复值及异常选项，合法空目录仍为空目录。

知识文章与分类通过 allSettled 独立读取/投影，任一失败不丢弃另一侧。雪场标签失败也不影响雪场列表；表单、已有筛选、上一页/下一页、空后续页和错误重试沿用既有实现。错误不展示原始服务端或内部解析诊断。没有将全部详情 VO、评论、收藏命令或管理端协议纳入这次列表修复。

## 验证

新增 48 项回归，其中 43 项覆盖原七项问题、分页/游标/目录异常、重复值、投影裁剪、精确金额/签名 URL、同步抛错及超时迟到响应；另外 5 项通过真实 Node HTTP/fetch 和生产 ApiClient 验证五个端点的信封解析、查询编码、无凭证读取、401 无认证副作用、故障隔离、下次读取恢复，以及两条停滞响应正文在 10 秒后关闭。与首页、元数据和三个目录既有测试合计 9 文件 192 项通过，已纳入既有 test:web-resorts 和完整 check，不新增测试命令。

本端类型检查和变更文件 ESLint 通过。初轮专项除新增七项转绿外，有三处旧测试仍只接受 no-store，已更新为精确核对匿名、取消信号和禁止刷新选项；失败与成功日志保留。完整三仓冻结安装/check、构建/导出和文档审计结果见阶段交付记录。

本轮 Web check 的契约、边界、lint、类型、1841 项业务及 20 项发布测试通过后，在最后一步发现新增测试文件的格式问题，命令退出 1；仅格式化该文件后单独复验 format:check。保留原失败日志与格式复验结果，不将首个 check 进程记为退出 0；没有因格式问题重复执行已通过的业务测试。

查阅已安装 Next.js 16.3.5 的 Fetching Data、Vitest 文档，保留服务端异步读取和同步视图。HTTP 服务仅为合成协议，SSR/请求替身不等于真实 Next 异步页面、Nest/PostgreSQL、浏览器 Cookie、分享抓取或设备验收。取消依赖生产 fetch 遵守 AbortSignal，不能保证任意忽略信号的替身都在 10 秒内结算；计时也不能抢占同步 JSON/投影执行。Docker 保持原状，未重试此前被自动审批拒绝的服务启动；D-49/D-50/D-51 仍分别等待此前确认。
