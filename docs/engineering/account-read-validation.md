# 账号管理读取边界与恢复

日期：2026-11-03。页面 ADM-05/ADM-06，接口 API-M02。沿用账号/角色目录接口和生成 VO；不新增 API、权限键、迁移或角色业务规则。

`features/users/user-response.ts` 对账号详情、列表、角色目录显式投影。账号只保留编号、账号、昵称、状态、创建时间、关联角色和商家摘要；角色、商家和数据范围的嵌套额外字段同样剔除。校验正 int4、状态、日期、非空名称、唯一编号、分页和非负统计，列表核对已选状态。后续空页可以保留真实 total。角色目录仍逐页读取完整活动目录，单页或后续页异常不返回部分可选角色；跨页不宣称事务快照。

`readAccountPage`、`readAccountDetail`、角色目录和未知写入结果核对都在读取前后复核 `/auth/me`。本地身份先通过现有会话解析器校验；账号、用户 ID、角色、grants 或商家关联改变即拒绝返回，工作区隔离键补上账号。没有假定商家角色键，账号数据范围及最后管理员保护仍由后端负责。`readAccountTarget` 是供既有写前准备使用的低层目标读取，只保证目标编号和响应投影；页面通过带身份复核的高层读取器使用它。

列表在隐藏或 pagehide 时取消列表和编辑准备、清空账号/目录/目标及表单；返回后显式刷新。刷新回调复核当前操作者和筛选，避免旧回调启动错误条件读取。详情同样取消并清空数据，固定“刷新账号详情”入口在等待状态也可用；旧请求即使迟到也不能发布。隐藏期间不自动重读。已开始的写入不因列表读取变化被认定失败；既有同步写锁和未知结果台账规则保持。

创建结果核对继续使用规范化账号精确匹配，不将“不可见/未找到”当作创建失败；新增完整列表校验和结束身份复核。没有新服务端幂等或版本字段，读取前后身份比较也不是授权租约或完整数据范围版本校验。

验证见[本轮结果](../validation/account-reads-20261103.json)。新增 28 项边界测试先全部失败，随后修复；页面可见性测试通过模拟 effect/EventTarget 与延迟响应验证接线，不代表真实 React 浏览器或 BFCache 验收。实际 HTTP 通过生产读取器连接编译 Nest 与隔离 PostgreSQL，检查账号完整投影、后续空页、自定义角色 self 范围、其他账号 404 和读取期间实际撤权。商家建档 D-49、雪场原因 D-50 和注销 D-09 保持待决；真实浏览器/设备、Kafka、供应商、容器、签名包和远程 CI 仍待验。
