# 动态字段完整响应与页面生命周期

日期：2026-11-03。负责人：Web。沿用 OpenAPI 1.51.1 / 143 操作，无新接口、依赖或迁移。当前验证结果统一记录在[本仓摘要](../validation/field-reads-20261103.json)。

字段定义、字段分组、列表和编辑详情现在从 `unknown` 解析，只返回生成 VO 声明的属性。检查实体、主键、字段键/分组键、类型、状态、排序、布尔标记、版本及时间；分页保持 `page/pageSize/total/items`，没有增加 `hasNext`。分组列表仍检查重复键，字段列表仍检查重复 ID 和筛选状态。

默认值保持任意合法 JSON，明确保留 `false`、`0`、空字符串和 `null`；验证规则和可见规则保持可空 JSON 对象。复制 JSON 时拒绝非有限数字、undefined、函数、循环引用、稀疏数组及非 JSON 对象，不调用 `toJSON`，不复用响应对象引用。JSON 对象内的业务键按存储内容保留，VO 外的附加属性不进入表单。

创建、更新、启用字段及创建、更新分组的成功响应使用同一解析器，并核对原目标、实体、字段键、版本或预期状态。无法解析的成功响应按结果未知处理，保留原有写入恢复记录，不能立即重复发送。DELETE 沿用现有 204 协议。

读取前后复核身份与具体查询权限；本地身份在请求及表单准备前也经过解析。工作区隔离包含账号 ID、账号名、商家资料 ID、角色键、权限集合和实体类型。商家归属仍来自身份上下文，不硬编码商家角色。后端继续执行最终授权；前后两次身份读取不构成跨请求的原子快照。

页面隐藏或收到 `pagehide` 时取消字段、分组及详情读取，停止写入准备，清空列表、编辑目标和两类表单。回到前台后由操作者显式刷新；不自动重放命令。详情准备使用同步锁，避免 React 状态更新前重复打开编辑。生命周期代次使隐藏之前的编辑或核对结束回调不能解锁新的操作。

已有[写入恢复账本](field-write-recovery.md)继续按账号与实体保存已发送请求。隐藏页面不会清除在途或未知写入；只读核对仍要求所有必要查询成功、无在途请求、账本版本未改变，再由操作者确认。浏览器标签页关闭、重新加载后内存账本仍会丢失，没有新增跨标签页或服务器幂等协议。

验证入口为 `pnpm test:admin-fields` 和 `pnpm test:admin-authorization-http`。后者通过 Node Cookie/CSRF 适配访问编译 Nest 和临时 PostgreSQL，覆盖生产读取器、字典选项字段生命周期、旧版本 409、启用字段阻止分组停用、软停用以及实际读取期间撤权。后置夹具独立核对最终版本、字段/分组状态、默认值、字典关联及七条成功审计。页面测试使用模拟 Hooks/EventTarget；真实浏览器、BFCache 和设备验收仍未覆盖。
