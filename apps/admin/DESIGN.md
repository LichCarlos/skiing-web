# 管理端界面规范

2026-11-06 精修：后台以完成任务为优先，白色外壳承载高密度操作；蓝色当前导航、黄色品牌细节、红/橙指标标识延续撞色身份。总数和失败数与细分状态建立明确层级，收益以蓝色强调。所有数据和权限规则保持不变，不用整块高饱和背景代替数据层级。方法和来源见[研究说明](../../docs/engineering/ui-design-research-20261106.md)。本轮本地完成，未重新部署。

按最新要求，品牌以电光蓝 `#2455F5` 为主体，搭配红 `#DC2F43`、亮黄 `#EFFF46`、橙 `#FF9A3C` 的多巴胺撞色。浅蓝 `#EEF7FF` 与白色承担正文、表单和表格背景，深蓝 `#17264C` 用于文字。鲜艳底色必须配套对应前景色；不使用紫色品牌色。

## 主题与控件

- `src/config/theme.ts`：Ant Design 组件主题，操作主色 `#2455f5`，浅蓝选中底色 `#e5efff`，内容白底，页面底色 `#eef7ff`，分隔线 `#cbd9ef`。
- `src/styles/aliases.css`：管理端语义变量，包括页面间距、侧栏尺寸、提示状态和浮层阴影。
- `src/styles/console.module.css`：各功能的页面、筛选区和错误反馈样式；通过 CSS Modules `composes` 复用。
- `src/styles/globals.css`：本端表格、分页、浮层、焦点和减少动态效果设置；共享包和官网不受修改影响。
- 使用系统无衬线字体。页面标题 24px，分区标题 18px，控件与正文主要为 14px，辅助信息为 12–13px。数字、金额和表格使用等宽数字。
- 普通控件高 38px，登录页主要控件高 44px。面板圆角 12px，控件圆角 8px；不用大面积装饰阴影。
- 中文分页、弹窗和表单基础提示由 Ant Design 中文 locale 提供。业务校验和请求反馈继续由各功能维护。

## 导航与布局

2026-11-09：管理端按桌面操作优化，左侧固定展示 Ant Design Menu，可展开收起业务分组；当前路由自动展开所在组。菜单与工作台由同一前端模块表生成，商家专属功能同时检查有效商家绑定和页面权限；系统功能仍按独立授权显示。后台外壳最小宽度1120px，不再因窄屏切换手机导航；下方旧版手机规则属于历史设计。

桌面头部高 64px，左侧导航宽 232px；侧栏独立滚动。导航按内容运营、商家经营、账号与权限、系统设置、AI 与任务分组；分组和模块只能来自现有权限过滤结果，空分组不显示。当前模块采用最长路径前缀匹配，父级概览与子页面不能同时高亮。

宽度不超过 1024px 时，侧栏改为带焦点管理的 Drawer；选择模块后关闭。宽度不超过 768px 时，页面间距由 32px 改为 16px，常见筛选控件分行。宽度不超过 672px 时，头部省略面包屑与长昵称，保留品牌、导航按钮、头像和退出入口。

表格宽内容只在表格自身横向滚动。表单使用可收缩网格，小屏变成单列。工作台用紧凑的统计面板和分组链接展示真实授权数据；不生成演示业务数字。

消息任务、操作日志与 AI 运维查询表单使用 `styles/console.module.css` 的 `queryForm`：白底筛选面板、顶部标签、自适应列宽，输入区最小列宽14rem，窄屏单列；`queryActions` 独占一行承载查询及次操作。原生时间选择保留本地时区及秒级精度，禁止通过无间距的 inline 布局堆叠筛选项。

## 交互与状态

管理段落由 AdminParagraph 内的 Typography.Text 呈现，保持既有段落语义和状态色。所有可填写 Form.Item 通过 FormHint/extra 提供13px规则小字；独立筛选控件使用 ControlHint 显示并关联说明。动态字段读取实际约束生成说明，权限、单位、数值范围和长度需与保存校验一致。

保留原有 API、权限、提交门禁、会话恢复、原因填写及结果核对逻辑。主操作使用主色按钮，次操作使用普通按钮，危险操作沿用语义危险色与确认流程。表格保持悬停反馈与稳定的分页区。加载汇总时显示 Skeleton，并保留可读状态文本。

交互元素必须有可见键盘焦点；头部提供跳至主要内容链接。减少动态效果的系统偏好应生效。使用统一线宽的 SVG 图标，图标旁有文字时作为装饰隐藏，不使用图标推断权限或业务身份。

普通链接的全局文字色必须排除 `.ant-btn`：带 `href` 的 Ant Design 按钮也是锚点，由组件主题管理正常、悬停、按下和禁用配色，避免蓝底蓝字。主按钮白字与蓝底的正常对比度约 5.69:1。

字典与字段管理配置项使用 `components/form-hint`（Ant Design Typography.Text）提供13px辅助说明，通过 Form.Item extra 放在控件下方，关联字段的可访问说明。说明使用语义辅助色，区分稳定键、显示名、保存值、使用条件和示例；长说明自然换行，字段开关使用自适应网格。

新增分类先下拉选择真实支持的所属字段，自动对应字典及分组，再填写选项；扩展字段的字典/分组引用使用有效配置下拉并提供加载、无权限、失效和重试状态。非选择类型隐藏字典绑定并清除旧值。新增选项字典按业务生成唯一标识，技术键只读显示供核对。

数据字典的实体关系图按需加载 React Flow，使用真实 DOM 节点及现有蓝白配色；实体浅蓝、字典浅黄、固定字段浅灰，文字保留高对比度。关系来自 API 中的实体、复合分组键及 optionsDictType，禁止根据归类前缀猜测绑定。图中点击与搜索均可管理节点，默认聚焦字典引用，可开启全部字段；640px以下使用 DOM 关系树，详情在树下方。字典项目使用 Ant Design Tree 与 TreeSelect，支持展开、搜索、新增子项与父级选择，保存沿用既有门禁。

路由错误页面在 Provider 失效时仍需显示，因此保留主题变量的明确回退值。

字典图与字段图提供带虚线边框的“新字典／新字典项／新分组／新字段”节点工具，拖至兼容位置后打开现有表单；点按按钮提供键盘和触屏替代。拖入只带入目标上下文，保存后才更新实际结构。字典树原有节点拖动后弹窗核对父级，禁止循环；字段图采用可读的初始缩放及搜索定位，手机保留层级树。拖拽经过的画布显示蓝色轮廓。

## 扩展方式

优先使用现有 Ant Design 组件，通过本端主题配置统一外观。新页面复用通用 CSS Modules，再增加本功能的布局样式。不要直接改共享官网样式，也不要为单个页面安装另一套完整后台组件库。选型比较见 [管理端样式与组件库](../../docs/engineering/admin-ui-system.md)。
