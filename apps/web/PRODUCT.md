# 凛迹雪客官网

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

游客和普通用户浏览滑雪场、滑雪知识、雪友动态。商家和系统管理员使用独立的 RBAC 管理端，官网不替代后台。

## Product Purpose

帮助用户发现站内雪场、阅读知识、浏览雪友分享并通过稳定 ID 进入站内详情。官网个人中心支持使用 Tiptap 书写雪友笔记、管理本人笔记、查看收藏，以及通过既有 AI 接口查看本人历史对话和连续提问；沿用既有社区权限，提交及公开内容修改都需管理员审核。

## Capabilities and Constraints

Next.js + TypeScript；web 内官网/后台为独立应用，backend/app又各属独立仓库。使用既有公开 API 和真实公开内容；不能为了视觉捏造商家、票价、评分、统计或评价。保留收藏、会话、权限、审核等既有行为。

## Brand Commitments

用户于2026-11-06确认参考UNITS的常驻导航、展开目录和纵滚横移体验；蓝主体，红黄橙紫、白底、圆角、像素元素、纯黑边框。移动采用适合触摸的简化导航，阅读不被营销动效打断。

2026-11-07 用户确认官网原白底区域与个人中心使用参考肤色 `#F4E9E1`，保留首页及栏目彩色背景。

## Evidence on Hand

既有公开内容 API、当前上传封面、`src/features/home/assets` 中的品牌雪山氛围图。氛围图不代表具体雪场实拍；公开动态可能包含明确标注的演示故事，不作为真实游客评价。

## Product Principles

- 视觉升级不改变业务真相和公开权限。
- 无JS、减少动画、API失败时仍能找到目录并读已有内容。
- 真实地图需要供应商、合法地理数据和坐标核验；尚未接入时如实说明。

## Open Decisions

正文多雪场关系、服务端持久草稿、地图供应商及Key/预算、DEM与原生地图方案仍待确认。2026-11-07 已按用户授权部署个人中心，使用既有 Markdown 内容契约及单雪场关联；用户笔记沿用社区审核。
